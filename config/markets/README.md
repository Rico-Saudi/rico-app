# إعداد الأسواق

كل ما يفرّق بناءً عن بناء. السوقان **هنا معاً على الفرع الأساسي**، لا كل سوق
على فرعه — لأن ميزة تُكتب على فرع تبقى فيه، وهذا ما جمّد `rico-jo`
(ناقصه ٥٠ ألف سطر) و`rico-saudi` (٢٨ ألف سطر) قبل اليوم.

| | السعودية | الأردن |
|---|---|---|
| الملف | `saudi.json` | `jordan.json` |
| `RICO_BRAND` | `rico` | `tadallal` |
| الاسم الذي يعرّف به | ريكو | تدلل |
| اللهجة | سعودية | أردنية |
| العملة | ر.س | د.أ |
| بلد البحث | SA | JO |

اللهجة والعملة وبلد البحث **ما تُضبط هنا**: الخادم يشتقّها من `RICO_BRAND`
(انظر `brands.ts`). راية واحدة تحدّدها كلها، فلا يصير بناءٌ يقول «تدلل»
ويسعّر بالريال.

## البناء

```bash
# السعودية
flutter build appbundle --dart-define-from-file=config/markets/saudi.json

# الأردن
flutter build appbundle --dart-define-from-file=config/markets/jordan.json
```

على فرعي `rico` و`tadallal` يوجد `market.json` في الجذر، وهو **رابط رمزي**
لملف سوق الفرع — لا نسخة منه. فالقيم تبقى في مصدر واحد، ولا يقدر فرعٌ
ينحرف عن الآخر في عنوان أو سلوق. أمر البناء واحد على الفرعين:

```bash
flutter build appbundle --dart-define-from-file=market.json
```

`market.json` موجود على فرعي السوقين فقط، لا على الأساس — فدمج الأساس في
أيٍّ منهما لا يلمسه أبداً ولا يصطدم به.

> على ويندوز قد لا يُنشئ git الرابط الرمزي بل ملفاً نصياً فيه المسار. يفشل
> البناء حينها فشلاً صريحاً (JSON غير صالح) لا صامتاً؛ والحل تمرير المسار
> الكامل: `--dart-define-from-file=config/markets/jordan.json`.

## التجربة المحلية

```bash
flutter run --dart-define-from-file=config/markets/jordan.json \
            --dart-define=RICO_API=http://localhost:3000
```

`--dart-define` تتقدّم على الملف، فتبدّل الخادم وحده وتبقي السوق.

## الخادم

نفس الباكند يُنشر مرتين — لا فرع له ولا نسخة. كل نشرة متغيّراتها الخاصة
(`MONGODB_URI`، `SESSION_SECRET`، مفاتيح الخدمات)، والسوق يجي من `brand`
في كل نداء لا من مكان النشر: خادم واحد يقدر يخدم السوقين معاً، وهذا مقصود
في `brands.ts`.


## ⚠️ قبل أول إصدار أردني

`RICO_API` في `jordan.json` مكتوب `https://app.tadallal.com` **كمبدئي غير
مؤكَّد** — ضعه على عنوان خادم الأردن الفعلي. خطأٌ هنا يعني تطبيقاً أردنياً
ينادي خادماً لا وجود له، أو أسوأ: خادم السعودية.
